# SENTINEL NovaPay

Modelo de detección de fraude con XGBoost, desplegado vía FastAPI en AWS EC2.
Métricas: 99.76% recall, 99.21% precision.
Explicabilidad de las predicciones mediante Llama 3 (vía Groq).
