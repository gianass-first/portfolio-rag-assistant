# Absenteeism at Work

Modelo de predicción de ausentismo laboral mediante Ridge Regression.
Métrica: MAE de 3.893 horas.

Productizado en Streamlit con 3 páginas:
- Predictor individual (estimación de ausentismo para un empleado puntual).
- Simulador masivo vía CSV (carga de múltiples empleados a la vez).
- Calculadora de ahorros (estimación del impacto económico de reducir el ausentismo).
